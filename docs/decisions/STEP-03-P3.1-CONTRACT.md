## 1. Objective

Stand up the deterministic render pipeline the whole site is generated by: data in, tokens applied, HTML out, with self-hosted subset fonts and a CI workflow that publishes to GitHub Pages. No page content is wired in this phase — the pipeline is the deliverable, not the site.

**Exit criterion:** `python build.py` renders a skeleton of all five pages from `data/*.json` with zero third-party origins in the output and zero colour literals outside `tokens.css`, the shipped font subsets are proven to carry every glyph the design uses, and the deployed URL serves that output over HTTPS.

## 3. Requirements

- **3.1** The D-01 identity is set **before the first commit exists**: `git config --global user.email "263689115+MohdSaifHussain@users.noreply.github.com"`, `user.name` unchanged. *Standard: C-33.* Commit authorship is immutable once pushed; this ordering is not negotiable within the phase.
- **3.2** No colour, type-step, or spacing literal appears anywhere except `tokens.css`. Templates and `site.css` reference custom properties only. *Standard: STEP-02 §1.*
- **3.3** Shipped HTML contains **zero inline `<script>` bodies and zero `style=` attributes**, from the first template onward, so the P3.4 CSP refactor is a no-op rather than a rewrite. *Standard: C-18, decision D-05.*
- **3.4** Fonts are fetched from their official upstreams, cited by URL in `DECISIONS.md`, never from a CDN or a memory of a URL. *Standard: doctrine rule 3; C-04.*
- **3.5** The subsetting step emits a **coverage report proving the presence of every codepoint the design uses**: `✓ U+2713`, `✗ U+2717`, `● U+25CF`, `↗ U+2197`, `· U+00B7`, `— U+2014`, `≥ U+2265`, `× U+00D7`, plus Latin. A missing glyph silently falls back to a system font and breaks the motif — so absence is a logged defect with a decided fallback, not a shrug. *Standard: C-04, STEP-02 §2 (motif).*
- **3.6** `build.py` fails loudly with a **distinct reason code per failure mode** (missing data file, malformed JSON, unknown token reference, missing template). *Standard: doctrine rule 5.*
- **3.7** `build.py` is deterministic: the same inputs produce byte-identical `_site/` output. *Standard: C-34; verified by double-run hash comparison.*
- **3.8** Every command written into this contract or the SOP is PowerShell 5.1-safe — `;` and `if ($?)`, never `&&`. *Standard: C-36, charter §8.*
- **3.9** `DECISIONS.md` records the **D-02 deviation from the frozen handoff** (version anchors + evidence links change §3's truth strip and §4's card) as a deviation with the ruling that authorised it. *Standard: doctrine rule 10; charter §8 amendment rule.*

## 4a. Review stop

**Halt after D1–D5, before D6 and D8.** Two reasons the stop falls exactly there:

1. **Something becomes immutable at D8.** Once the first commit is pushed to a public repo, its author field cannot be corrected without a force-push over published history. Template 4's rule — stop before the thing sets, not after — puts the stop before the push, not after it.
2. D2–D4 are load-bearing: every page in every later phase is generated by that pipeline and rendered in those fonts. D6/D8 are delivery. A pipeline defect found after four phases of content sit on top of it is found too late.

At the stop I will prove, by quoting exact lines with file and line numbers: the reason codes of 3.6 firing; the determinism of 3.7; the glyph coverage of 3.5; and that no literal escapes `tokens.css` per 3.2.
